CFin

yfinance for China

CFin is a FastAPI web service for stock price retrieval and markdown article publishing. It wraps yfinance to expose historical market data as JSON, and serves uploaded markdown files as styled HTML pages.

OpenAPI Docs ReDoc Markdown Workspace Sample Article Health Check

What it does

Stock data

Query full historical price data for any ticker supported by yfinance and receive a JSON payload with OHLCV fields.

Markdown publishing

Upload markdown files, list them in a simple workspace, and render them as GitHub-style HTML in the browser.

Static site

Bundled HTML, CSS and images are served from the application, including this landing page and the project logo.

Gzip and OpenAPI

Responses larger than 2 KB are compressed, and the full API schema is available at /openapi.json.

Service endpoints

All routes are relative to the service root. Routes marked as internal are hidden from the OpenAPI schema but remain available.

Method Path Description Response
GET / Redirect to the landing page. 307 to /static/index.html
GET /health Service health probe. {"status": "Ok!"}
GET /docs Swagger UI for interactive API testing. text/html
GET /redoc ReDoc reference generated by FastAPI. text/html
GET /openapi.json OpenAPI schema for the service. application/json
GET /stock/{ticker} Historical price data from yfinance using the maximum available period. application/json
GET /markspace Markdown file manager with upload form and file listing. text/html
GET /resource/{article_name} Render a markdown file as a styled HTML page. text/html
POST /upload Upload a markdown file as multipart form field uploadFile. Spaces in the filename become dashes. {"status": 200}
GET /download/{article_name} Download a stored markdown file. application/octet-stream
GET /static/* Static assets including HTML, images and styles. File content by type

Quick start

Query a ticker and fetch a rendered article with curl.

# Fetch the full price history for Apple
curl http://127.0.0.1:8000/stock/AAPL

# Render the bundled sample markdown file
curl http://127.0.0.1:8000/resource/sample.md

# Upload a local markdown file
curl -F "uploadFile=@notes.md" http://127.0.0.1:8000/upload

Run locally

Install

uv sync --extra dev

Start

uv run cfin

Test

uv run pytest

The service listens on port 8000 by default. Configure it with CFIN_HOST, CFIN_PORT, CFIN_RELOAD and CFIN_DEBUG.
